# Code of Conduct

This project follows a simple rule: be respectful.

## Expected behaviour

- Treat others with courtesy.
- Assume good faith when interpreting comments.
- Focus discussion on the work, not the person.
- Respect different opinions and experience levels.

## Not OK

- Personal attacks, harassment, or sustained disruptive behaviour.
- Sharing private information without consent.
- Behaviour that would be inappropriate in a professional setting.

## Enforcement

Maintainers may remove comments, commits, or pull requests that violate this rule. Serious or repeated violations may result in a ban from contributing.

For issues, email marketing@zsky.ai.
