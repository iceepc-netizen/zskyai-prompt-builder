# Contributing

Thanks for your interest in contributing to a ZSky AI project. We welcome pull requests, issues, and discussion.

## Before You Start

- Read the README to understand what the project does and how it is used.
- Search existing issues and pull requests to avoid duplicating work.
- For larger changes, open an issue first to discuss the approach.

## Reporting Bugs

Open an issue using the "Bug report" template. Include:

- The version or commit you are on
- A minimal, reproducible example
- What you expected to happen vs. what actually happened
- Logs, stack traces, or screenshots if relevant

## Requesting Features

Open an issue using the "Feature request" template. Describe the use case and why the current behavior is not enough. Concrete examples help a lot.

## Pull Requests

1. Fork the repository and create a feature branch off `main`.
2. Make your changes in small, focused commits with clear messages.
3. Add or update tests where applicable.
4. Run any project-local linters, formatters, and tests before opening the PR.
5. Open the pull request against `main`. Fill out the PR template.
6. Be prepared to iterate on review feedback. We aim to respond within a few business days.

## Code Style

- Follow the conventions already used in the file you are editing.
- Keep changes ASCII unless the project already uses other characters.
- Prefer clarity over cleverness.

## Commit Messages

- Use the imperative mood ("Add X", "Fix Y").
- First line is a short summary under 72 characters.
- Body, if present, explains the why and any tradeoffs.
